개인정보처리방침

이어생각 (ThinkFlow) · 시행일: 2026년 10월 8일

요약: 이어생각에 쓴 생각은 기기 밖으로 나가지 않습니다.
회원가입도 광고도 분석 도구도 없습니다. 기기 밖으로 전송되는 것은 사용자가 직접 ‘피드백 보내기’로 보낸 내용뿐입니다.

1. 수집하는 개인정보

이어생각은 회원가입이 없고, 앱을 쓰는 동안 이름·이메일·위치·기기 식별자 같은 개인정보를 수집하거나 서버로 보내지 않습니다. 사용 기록이나 사용 통계도 모으지 않습니다.

예외는 사용자가 설정 화면의 피드백 보내기에서 직접 보내는 경우 하나입니다. 이때 아래 내용이 개발자에게 전달됩니다.

  • 사용자가 쓴 피드백 내용과 종류(버그 제보·개선 제안 등)
  • 사용자가 직접 고른 스크린샷 (첨부한 경우에만)
  • 사용자가 직접 적은 이름과 이메일 (답장을 받고 싶어 입력한 경우에만)
  • 문제 확인에 필요한 기술 정보: 앱 버전, 기기 모델, iOS 버전, 언어·지역 설정

피드백은 Apple의 iCloud(CloudKit) 저장소를 통해 개발자에게 전달되며, 문의에 답하고 앱을 고치는 데에만 씁니다. 보낸 피드백에 대한 답장을 앱에서 보여 주기 위해 iCloud가 피드백 저장소 전용으로 발급하는 익명 식별자를 함께 사용합니다. 이 식별자로는 사용자의 Apple 계정이나 이름을 알 수 없습니다.

2. 데이터 저장 방식

앱에서 작성한 모든 내용(생각, 메모, 끊어둔 문장, 붙여둔 자료, 사고 시간 기록)은 다음 위치에만 저장됩니다.

  • 사용자 기기 내 앱 저장 공간
  • 위젯 표시를 위한 같은 기기 내 앱 그룹(App Group) 공유 저장 공간

이 데이터는 네트워크로 전송되지 않으며, 개발자를 포함한 누구도 접근할 수 없습니다.

3. 제3자 제공 및 외부 서비스

이어생각은 광고 SDK, 분석(애널리틱스) SDK, 소셜 로그인 등 제3자 서비스를 쓰지 않으며, 수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 피드백 전달에 쓰는 iCloud(CloudKit)는 Apple이 운영하는 저장소로, Apple의 개인정보 처리방침을 따릅니다.

4. 진단 정보

앱이 비정상 종료되거나 멈춘 경우 iOS가 제공하는 진단 정보(MetricKit)를 받아 기기 안에만 보관합니다(최근 20건). 이 정보는 자동으로 전송되지 않으며, 사용자가 작성한 내용도 들어 있지 않습니다.

또한 사용자가 iOS 설정에서 앱 개발자와 진단 데이터 공유에 동의한 경우, Apple이 익명화된 충돌 보고서를 개발자에게 전달할 수 있습니다. 이 설정은 iOS 설정 > 개인정보 보호 및 보안 > 분석 및 향상에서 언제든지 바꿀 수 있습니다.

5. 데이터 백업과 삭제

  • 앱 내 내보내기 기능으로 전체 데이터를 마크다운 또는 JSON 파일로 직접 백업할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 즉시 함께 삭제됩니다.
  • 보낸 피드백의 삭제를 원하면 아래 문의처로 알려 주세요. 확인 후 지체 없이 삭제합니다.
  • 기기의 iCloud 백업 설정에 따라 앱 데이터가 사용자 본인의 iCloud 기기 백업에 포함될 수 있습니다. 이는 iOS의 표준 동작이며 개발자는 접근할 수 없습니다.

6. 아동의 개인정보

이어생각은 아동을 포함한 누구의 개인정보도 앱 사용 중에 수집하지 않습니다. 피드백으로 받은 정보 가운데 아동의 정보가 있음을 알게 되면 바로 삭제합니다.

7. 방침 변경

이 방침이 변경되는 경우(예: 새로운 기능으로 데이터 처리 방식이 달라지는 경우) 이 페이지를 통해 고지하며, 시행일을 갱신합니다.
