개인정보처리방침

이어생각 (ThinkFlow) · 시행일: 2026년 6월 11일 · 최종 수정일: 2026년 10월 16일

요약: 이어생각은 개인정보를 수집하지 않습니다.
작성한 생각과 메모는 사용자의 기기 안에만 저장되며, 외부로 전송되지 않습니다. 개발자에게 가는 것은 누가 썼는지 알 수 없는 익명 사용 통계·오류 보고와, 사용자가 직접 보낸 의견뿐입니다.

1. 수집하는 개인정보

이어생각은 개인정보를 수집하지 않습니다. 회원가입이 없고, 개발자가 운영하는 서버도 없으며, 이름·이메일·위치·기기 식별자 같은 정보를 수집하지 않습니다. 예외는 아래 3항의 익명 사용 통계와 4항의 의견 보내기입니다.

2. 데이터 저장 방식

앱에서 작성한 모든 내용(생각, 메모, 끊어둔 문장, 붙여둔 자료, 사고 시간 기록)은 다음 위치에만 저장됩니다.

  • 사용자 기기 내 앱 저장 공간
  • 위젯 표시를 위한 같은 기기 내 앱 그룹(App Group) 공유 저장 공간

이 데이터는 네트워크로 전송되지 않으며, 개발자를 포함한 누구도 접근할 수 없습니다.

3. 익명 사용 통계와 진단 정보

앱을 몇 명이 쓰는지 알고 오류를 고치기 위해, 다음 익명 통계를 Apple iCloud(CloudKit)로 보냅니다. 개발자만 읽습니다.

  • 설치할 때 만든 무작위 ID (기기·Apple ID·다른 앱과 연결되지 않으며, 다시 설치하면 바뀝니다)
  • 앱 버전, iOS 버전, 지역·언어 설정
  • 앱을 연 횟수와 앱을 연 날, 설치한 날짜와 설치 후 지난 날수
  • 앱이 멈추거나 비정상 종료됐을 때의 진단 보고 (앱 버전, iOS 버전, 기기 종류, 오류의 기술적 정보)

이름, 연락처, 위치, 작성한 생각·메모 같은 내용은 포함하지 않습니다. iCloud에 로그인되어 있을 때만 보냅니다. 진단 보고는 Apple의 표준 진단 체계(MetricKit)가 앱에 넘겨준 것으로, iOS 설정 > 개인정보 보호 및 보안 > 분석 및 향상의 설정에 따라 생성되지 않을 수도 있습니다.

4. 의견 보내기 (사용자가 직접 보낼 때만)

앱이 가끔 묻는 만족도 질문에서 아쉬운 점을 골라 의견을 작성해 보내면, 고른 종류와 작성한 글, 앱 버전·iOS 버전·기기 종류·언어 설정이 Apple iCloud(CloudKit)를 거쳐 개발자에게 전달됩니다. 이름·이메일은 답장을 받으려고 직접 적었을 때만 함께 보냅니다. 사용자가 보내기 버튼을 누르기 전에는 아무것도 전송되지 않으며, 보낸 의견은 답장과 앱 개선에만 씁니다.

5. 제3자 제공 및 외부 서비스

이어생각은 광고 SDK, 외부 분석 서비스, 소셜 로그인 같은 제3자 서비스를 사용하지 않으며, 제3자에게 정보를 제공하지 않습니다. 익명 사용 통계와 의견 보내기에 쓰이는 iCloud는 Apple이 운영하며, Apple의 개인정보 처리방침이 적용됩니다.

6. 데이터 백업과 삭제

  • 앱 내 내보내기 기능으로 전체 데이터를 마크다운 또는 JSON 파일로 직접 백업할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 즉시 함께 삭제됩니다.
  • 기기의 iCloud 백업 설정에 따라 앱 데이터가 사용자 본인의 iCloud 기기 백업에 포함될 수 있습니다. 이는 iOS의 표준 동작이며 개발자는 접근할 수 없습니다.

7. 아동의 개인정보

이어생각은 개인정보를 수집하지 않으므로, 아동의 개인정보 또한 수집하지 않습니다. 3항의 익명 사용 통계에는 누가 앱을 쓰는지 알 수 있는 정보가 담기지 않습니다.

8. 방침 변경

이 방침이 변경되는 경우(예: 새로운 기능으로 데이터 처리 방식이 달라지는 경우) 이 페이지를 통해 고지하며, 시행일을 갱신합니다.
