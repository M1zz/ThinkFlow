ThinkFlow

ไม่จำเป็นต้องคิดให้จบในครั้งเดียว เครื่องมือสำหรับพักความคิด คิดต่อ และกลั่นกรองให้ชัดขึ้น

ThinkFlow คือแอปแบบไหน

เวลาที่งานเขียนกำลังลื่นไหล เฮมิงเวย์มักจงใจหยุดประโยคไว้กลางทางแล้วเลิกเขียนในวันนั้น เพราะประโยคที่ยังไม่จบช่วยให้เขากลับมาเขียนต่อได้อย่างเป็นธรรมชาติในวันรุ่งขึ้น ThinkFlow นำวิธีนี้มาใช้กับการคิด จดความคิดที่ผุดขึ้นมาไว้แบบสบาย ๆ และเมื่อจะหยุด ให้ทิ้งประโยคที่จะคิดต่อไว้ ครั้งหน้าที่เปิดแอป คุณจะคิดต่อจากประโยคนั้นได้ทันที

ฟีเจอร์หลัก

💭 ระบายความคิด (Brain Dump)

เทความคิดที่ลอยอยู่ในหัวออกมาให้หมดในคราวเดียว บรรทัดละหนึ่งความคิด แล้วเลือกเฉพาะความคิดที่อยากต่อยอดมาสร้างเป็นสายความคิด

🌉 ประโยคเชื่อมแบบเฮมิงเวย์

เมื่อจบช่วงเวลาคิด ให้เขียนประโยคที่ยังไม่จบไว้สำหรับคิดต่อครั้งหน้า เมื่อกลับมา บริบทตอนที่คุณหยุดไว้จะกลับมาทันที

📚 การสรุปแบบค่อยเป็นค่อยไป (Progressive Summarization)

กลั่นกรองความคิดด้วยการยกระดับโน้ตที่สะสมไว้ผ่านสี่ชั้น ได้แก่ โน้ต → จัดระเบียบ → ประเด็นหลัก → สรุป

📎 แนบผลค้นคว้าและข้อมูลอ้างอิง

คำตอบที่ได้จากการถาม Claude หรือข้อมูลที่ค้นมา แนบไว้ในสายความคิดเดียวกันได้ โดยแยกจากความคิดของคุณอย่างชัดเจน

📱 วิดเจ็ตและกิจกรรมสด

วิดเจ็ตบนหน้าจอโฮมจะแสดงประโยคเชื่อมของคุณเสมอ และระหว่างช่วงเวลาคิด ตัวจับเวลาจะแสดงบนหน้าจอล็อกและ Dynamic Island

คำถามที่พบบ่อย

ความคิดของฉันถูกเก็บไว้ที่ไหน

ความคิดทั้งหมดเก็บไว้ในอุปกรณ์ของคุณเท่านั้น ไม่มีการส่งไปยังเซิร์ฟเวอร์ และแม้แต่ผู้พัฒนาก็มองไม่เห็น สิ่งเดียวที่ออกไปนอกอุปกรณ์คือสิ่งที่คุณส่งเองผ่าน “ส่งความคิดเห็น” ในการตั้งค่า ดูรายละเอียดเพิ่มเติมได้ที่นโยบายความเป็นส่วนตัว

สำรองข้อมูลหรือย้ายข้อมูลไปที่อื่นได้ไหม

ที่เมนูส่งออกมุมขวาบนของหน้าแรกในแอป คุณส่งออกความคิดทั้งหมดเป็นไฟล์ Markdown หรือ JSON ได้ แล้วแชร์ไปเก็บไว้ในแอปไฟล์ โน้ต เมล หรือที่อื่นตามสะดวก

ถ้าลบแอป ข้อมูลจะเป็นอย่างไร

เมื่อลบแอป ความคิดทั้งหมดที่เก็บในอุปกรณ์จะถูกลบไปด้วย โปรดสำรองข้อมูลด้วยการส่งออกก่อนลบแอป

วิดเจ็ตไม่อัปเดต

วิดเจ็ตจะรีเฟรชอย่างน้อยทุก 30 นาที และเมื่อคุณเพิ่มความคิดในแอป ระบบจะขอรีเฟรชทันที หากข้อมูลที่แสดงดูเก่า ลองเปิดแอปสักครั้ง
