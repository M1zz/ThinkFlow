ThinkFlow

想法不必一次想完——先停下，再接着想，慢慢提炼

ThinkFlow 是什么

海明威在写得顺手的时候，会故意把一句话停在半截，就此结束一天的写作。 因为第二天，那句没写完的话会让他自然而然地重新开始。 ThinkFlow 把这个方法用在了思考上。随手把冒出来的想法写下来， 停下时留下一句可以接下去的话，下次打开，就从这句话直接接着想。

主要功能

💭 倾倒思绪（Brain Dump）

把脑子里飘来飘去的想法一行一行一口气写出来，再挑出值得深入的，变成一条条思路。

🌉 海明威之桥

结束一次思考时，写下一句下次要接着往下想的未完成的话（衔接句）。回来时，停下那一刻的来龙去脉会立刻重现。

📚 渐进式总结（Progressive Summarization）

把积累的备忘按“备忘 → 整理 → 要点 → 总结”四个层级逐步上提，让想法越来越清晰。

📎 附上调研结果与资料

向 Claude 提问得到的答案或搜索到的资料，可以和自己的想法区分开，附在同一条思路里。

📱 小组件与实时活动

主屏幕小组件随时显示你的衔接句；思考期间，锁定屏幕和灵动岛上会显示计时器。

常见问题

我的想法保存在哪里？

所有想法都只保存在你的设备上，不会上传到服务器，开发者也无法查看。唯一会离开设备的，是你在设置中通过“发送反馈”主动发送的内容。详情请参阅隐私政策。

可以备份数据或迁移到别处吗？

在首页右上角的“导出”菜单中，可以把全部想法导出为 Markdown 或 JSON 文件。分享到“文件” App、备忘录、邮件等处妥善保存即可。

删除 App 后数据会怎样？

删除 App 后，设备上保存的所有想法都会一并删除。删除前请先用“导出”功能备份。

小组件没有更新

小组件最长每 30 分钟刷新一次，在 App 中添加想法时也会立即请求刷新。如果显示的内容已经过时，请打开一次 App。
