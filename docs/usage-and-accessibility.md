# ThinkFlow 사용 시나리오 & 접근성 설계

> 이 앱의 본질: **생각을 한 번에 완성하지 않는다. 기세 있을 때 끊어두고(헤밍웨이 브릿지), 다음에 이어받아 점점 키운다.**

---

## 1. 사용 시나리오 — 누가, 언제, 어떻게

### 핵심 타깃 페르소나

| 페르소나 | 상황 | 사용 방식 |
|---|---|---|
| 1인 개발자 / 창작자 | 여러 아이디어를 동시에 장기간 굴림 | 스레드 여러 개를 병렬로 두고 진행 중/잠자는 생각을 오감 |
| 기획자 / 지식 노동자 | 이동·회의 틈새에 생각이 튐 | 브레인덤프로 쏟고, 틈날 때 하나씩 이어 깊이 파기 |
| 학생 / 연구자 | 강의·논문 인사이트가 날것으로 쌓임 | 메모(L0) → 정리(L1) → 핵심(L2) → 요약(L3) 점진 정리 |
| 작가 / 뉴스레터 운영자 | 글의 흐름이 끊기는 게 두려움 | 헤밍웨이 본래 용법: 쓸 게 남았을 때 다음 문장을 끊어두고 종료 |

### 하루의 흐름으로 본 시나리오

1. **아침 — 위젯에서 재진입**
   위젯에 "다음에 생각할 것"(끊어둔 문장)이 떠 있음 → 탭하면 바로 이어쓰기로 진입.
   *"어제 뭐 생각하다 멈췄지?"를 떠올릴 필요가 없다. 끊어둔 문장이 그대로 추진력.*

2. **이동 중 — 생각 쏟아내기 (브레인덤프)**
   떠다니는 생각 여러 개를 줄바꿈으로 쏟음 → "지금 당장 하나만 고른다면?"에서 하나만 골라
   스레드로 승격, 나머지는 보관함에 대기.

3. **막히기 전에 끊어두기 (핵심 의식)**
   이어쓰기를 닫으려면 반드시 "다음 문장"을 끊어둬야 함.
   *막혀서 멈추는 게 아니라, 아직 쓸 게 남았을 때 멈춘다.* 이게 다음 재진입의 추진력.

4. **며칠 뒤 — 되살리기**
   3일 이상 방치된 스레드는 "되살릴 생각"으로 분류 → 잊고 있던 사고를 끄집어냄.

5. **여유 있을 때 — 정리 단계 올리기**
   쌓인 메모를 레이어 칩으로 메모 → 핵심 → 요약으로 승급. 진행도 링이 차오르며
   "이 생각이 얼마나 여물었는지" 가시화.

> 한 줄 정의: **완성하려 애쓰지 않고, 끊고-이어붙이기를 반복해 생각을 키우는 사람을 위한 앱.**

## 2. 시각장애인 접근성 설계

### 왜 이 앱은 시각장애인에게 특히 잘 맞는가

전적으로 **텍스트와 사고** 기반이라 시각적 다이어그램이 없다. 더 중요한 건 —
헤밍웨이 브릿지의 "끊어둔 문장"을 VoiceOver가 가장 먼저 읽어주면, 화면을 다시 훑을 필요 없이
**곧바로 사고의 맥락으로 복귀**할 수 있다는 점. 접근성은 규정 준수가 아니라 이 앱의 정체성과
같은 방향이다.

### 핵심 읽기 흐름 (이어쓰기 시트)

```
끊어둔 문장  →  직전 생각  →  입력창(자동 포커스)
```
이 순서로 VoiceOver가 읽고 입력창에 자동 포커스되면, 시각장애인 사용자는 "여기서 끊어뒀어요"를
듣자마자 받아쓰기로 곧장 이어 말하기 시작할 수 있다. **이 읽기 순서 보장이 접근성의 핵심.**

### 구조 원칙 (우선순위)

| 순위 | 영역 | 조치 |
|---|---|---|
| 1 | 시맨틱 구조 | 섹션 제목 = 헤더 trait, 카드 = 단일 요소 + 명확한 액션 |
| 2 | 컨트롤 라벨 | 모든 아이콘 버튼에 `accessibilityLabel` (+ 필요시 `Hint`) |
| 3 | 탭 제스처 → 버튼 | 탭 제스처 전용 뷰를 시맨틱 버튼화, 부가 동작은 접근성 액션 |
| 4 | 음성 피드백 | 복사/레이어변경/저장/단계전환을 `UIAccessibility.post(.announcement)` |
| 5 | 포커스 관리 | 시트 단계 전환 시 포커스 이동 + 안내 |
| 6 | 저시력 | 고정 폰트 제거(Dynamic Type), 대비 상향 |

### 구현 체크리스트 (코드 반영 상태)

- [x] 홈 "+" 버튼, 복사/메뉴/정렬 아이콘 버튼에 라벨 부여
- [x] 섹션 제목("진행 중인 생각", "되살릴 생각", "생각의 흐름" 등)에 `.isHeader`
- [x] 덤프 항목 행을 `Button`으로 전환, 삭제를 접근성 액션으로 노출
- [x] 복사·레이어 승급 시 음성 안내(Announcement)
- [x] 엔트리 타임스탬프(상대+절대) 하나로 합치고 구분점 숨김
- [x] 입력창(`TextEditor`)에 라벨
- [x] 고정 크기 폰트(진행도 링 등) → Dynamic Type 대응
- [x] 통계 항목(메모/사고시간/깊이/시작일) 라벨+값 결합 읽기

### 향후 과제

- 이어쓰기/브레인덤프 단계 전환 시 `@AccessibilityFocusState`로 정밀 포커스 이동
- 대비비(Contrast) 측정 후 `.tertiary`/`.quaternary` 텍스트 상향
- 큰 글씨(최대 Dynamic Type)에서 레이아웃 깨짐 회귀 테스트
- 위젯/Live Activity 접근성 라벨
