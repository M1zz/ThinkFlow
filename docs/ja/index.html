ThinkFlow

考えは一度で仕上げなくていい。区切って、続けて、磨いていく思考ツール

ThinkFlowについて

ヘミングウェイは、筆が乗っているときにあえて文の途中で書くのをやめ、その日の仕事を終えていました。 翌日、その書きかけの文が、自然にまた書き始めるきっかけになったからです。 ThinkFlowは、この方法を「考える」ことに取り入れました。浮かんだ考えを気軽に書き出しておき、 手を止めるときは続きにつながる一文を残しておきます。次に開けば、その一文からすぐに続きを考えられます。

主な機能

💭 考えを書き出す（ブレインダンプ）

頭の中を漂っている考えを1行ずつ一気に書き出し、育てたいものだけを選んでスレッドにします。

🌉 ヘミングウェイ・ブリッジ

考える時間を終えるときに、次に続ける書きかけの一文（区切りの一文）を残しておきます。戻ってきたとき、止めたところの文脈がすぐによみがえります。

📚 段階的要約（Progressive Summarization）

たまったメモを、メモ → 整理 → 要点 → 要約の4段階のレイヤーへと引き上げながら、考えを磨いていきます。

📎 調べた内容・資料を貼る

Claudeに尋ねた結果や検索で見つけた資料を、自分の考えとは区別したまま、同じ流れに貼っておけます。

📱 ウィジェットとライブアクティビティ

ホーム画面のウィジェットに区切りの一文がいつも表示され、考えている間はロック画面とダイナミックアイランドにタイマーが表示されます。

よくある質問

考えたことはどこに保存されますか？

すべての考えはお使いのデバイスの中にだけ保存されます。サーバへ送信されることはなく、開発者が見ることもできません。デバイスの外に出るのは、設定の「フィードバックを送る」からご自身で送信した内容だけです。詳しくはプライバシーポリシーをご覧ください。

データをバックアップしたり、ほかの場所に移したりできますか？

ホーム画面右上の「書き出す」メニューから、すべての考えをMarkdownまたはJSONファイルとして書き出せます。「ファイル」App、メモ、メールなどに共有して保管してください。

アプリを削除するとデータはどうなりますか？

アプリを削除すると、デバイスに保存されているすべての考えも一緒に削除されます。削除する前に「書き出す」でバックアップしておいてください。

ウィジェットが更新されません

ウィジェットは最長30分ごとに更新され、アプリで考えを追加するとすぐに更新を要求します。表示が古いままのときは、一度アプリを開いてください。
