ThinkFlow

想法不必一次想完——先停下，再接著想，慢慢提煉

ThinkFlow 是什麼

海明威在寫得順手的時候，會刻意把一句話停在一半，就此結束一天的寫作。 因為隔天，那句沒寫完的話會讓他自然而然地重新動筆。 ThinkFlow 把這個方法用在思考上。隨手把冒出來的想法記下來， 停下時留下一句可以接下去的話，下次打開，就從這句話直接接著想。

主要功能

💭 傾倒思緒（Brain Dump）

把腦中飄來飄去的想法一行一行一口氣寫出來，再挑出值得深入的，變成一條條思考串。

🌉 海明威之橋

結束一次思考時，寫下一句下次要接著往下想的未完成的話（銜接句）。回來時，停下那一刻的脈絡會立刻重現。

📚 漸進式摘要（Progressive Summarization）

把累積的備忘依「備忘 → 整理 → 重點 → 摘要」四個層級逐步往上提煉，讓想法越來越清楚。

📎 附上研究結果與資料

向 Claude 詢問得到的答案或搜尋到的資料，可以和自己的想法區分開，附在同一條思路裡。

📱 小工具與即時動態

主畫面小工具隨時顯示你的銜接句；思考期間，鎖定畫面和動態島上會顯示計時器。

常見問題

我的想法儲存在哪裡？

所有想法都只儲存在你的裝置上，不會上傳到伺服器，開發者也無法查看。唯一會離開裝置的，是你在設定中透過「發送意見回饋」主動傳送的內容。詳情請參閱隱私權政策。

可以備份資料或轉移到其他地方嗎？

在首頁右上角的「匯出」選單中，可以把全部想法匯出為 Markdown 或 JSON 檔案。分享到「檔案」App、備忘錄、郵件等處妥善保存即可。

刪除 App 後資料會怎樣？

刪除 App 後，裝置上儲存的所有想法都會一併刪除。刪除前請先用「匯出」功能備份。

小工具沒有更新

小工具最長每 30 分鐘更新一次，在 App 中新增想法時也會立即要求更新。如果顯示的內容已經過時，請打開一次 App。
