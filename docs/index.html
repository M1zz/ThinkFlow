이어생각

생각을 한 번에 완성하지 않는다 — 끊어두고, 이어가고, 정제하는 생각 도구

이어생각은 이런 앱이에요

헤밍웨이는 글이 잘 풀릴 때 일부러 문장을 끊고 하루를 마쳤습니다. 다음 날 그 미완성 문장이 글쓰기를 자연스럽게 다시 시작하게 해 주었기 때문입니다. 이어생각은 이 방법을 생각에 적용합니다. 떠오른 생각을 가볍게 꺼내 두고, 멈출 때는 이어질 문장을 끊어두고, 다음에 열면 그 문장에서 바로 이어집니다.

주요 기능

💭 생각 꺼내기 (브레인 덤프)

머릿속에 떠다니는 생각을 줄 단위로 한 번에 쏟아내고, 키울 생각만 골라 스레드로 만듭니다.

🌉 헤밍웨이 브릿지

생각 세션을 끝낼 때 다음에 이어갈 미완성 문장을 적어 둡니다. 재진입할 때 멈췄던 맥락이 바로 복원됩니다.

📚 점진적 요약 (Progressive Summarization)

쌓인 메모를 메모 → 정리 → 핵심 → 요약 4단계 레이어로 올려가며 생각을 정제합니다.

📎 조사·자료 붙이기

Claude에게 물어본 결과나 검색한 자료를 생각과 구분해서 같은 흐름에 붙여 둘 수 있습니다.

📱 위젯 & 라이브 액티비티

홈 화면 위젯이 끊어둔 문장을 항상 보여주고, 생각 세션 중에는 잠금 화면과 다이내믹 아일랜드에 타이머가 표시됩니다.

자주 묻는 질문

내 생각은 어디에 저장되나요?

모든 데이터는 사용자의 기기 안에만 저장됩니다. 서버로 전송되지 않으며, 개발자도 볼 수 없습니다.

데이터를 백업하거나 다른 곳에 옮길 수 있나요?

홈 화면 오른쪽 위 내보내기 메뉴에서 전체 생각을 마크다운 또는 JSON 파일로 내보낼 수 있습니다. 파일 앱, 메모, 메일 등으로 공유해 보관하세요.

앱을 삭제하면 데이터는 어떻게 되나요?

앱을 삭제하면 기기에 저장된 모든 생각이 함께 삭제됩니다. 삭제 전에 내보내기로 백업해 두세요.

위젯이 업데이트되지 않아요

위젯은 최대 30분 간격으로 갱신되며, 앱에서 생각을 추가하면 즉시 갱신을 요청합니다. 표시가 오래되었다면 앱을 한 번 열어 주세요.
